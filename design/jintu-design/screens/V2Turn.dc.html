Your turn
About 5 minutes

Add your own notes file and save it as a second commit

Nobody gives you every command this time. Use your own name for the file.

Start with this
$mkdir notes
$echo "- Joined the team on Monday" > notes/asha.md

Then add the file, commit it with your own message, and run git log --oneline.

You are done when
The log shows two lines, newest first:
b0a90a5 Add my first note
4e230e0 Add README with project title
Your ids and message will differ. Two lines is what counts.
