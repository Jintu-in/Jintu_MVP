Add your own notes file and save it as a second commit

This time nobody gives you every command. Use your own name for the file.
$ mkdir notes echo "- Joined the team on Monday" > notes/asha.md

Now add the file, commit it with a message of your own, and run git log --oneline.

You are done when
The log shows two lines, newest first:
b0a90a5 Add my first note
4e230e0 Add README with project title
Your ids and your message will be different. Two lines is what counts.
